# ブロラボ SEO改善（2026-10-16）

## 実装

- ホームの戦績検索の直下に、戦績検索・Tier表・キャラ一覧・BAN・ピックツールの4入口を同じ大きさで配置。モード・マップ一覧への通常リンクを追加。
- ナビの「ダッシュボード」を「戦績検索」に変更。プレイヤー／クラブ切替、候補選択、検索処理を維持し、スマートフォンの入力欄・検索ボタンの幅を調整。
- Tier・モード・マップに共通の「総合／モード別／マップ別」リンクを配置。操作用のタブ・フィルターとは区別。モード・マップからBAN・ピックツールへリンク。
- キャラ一覧の検索・並べ替えを維持し、詳細リンクに用途と矢印を付与。詳細上部に既存の集計日時と、相性・おすすめマップ・モード別勝率への項目内リンクを配置。
- BAN・ピックツールのナビ・見出し・titleを統一。既存の初期設定→BAN→Pickの操作順と計算は維持。
- 戦績検索のtitleを「ブロスタ戦績確認ツール｜勝率・プレイヤー検索」に調整。既存descriptionは検索対象・勝率・履歴をすでに説明しているため維持。
- ホームとTierの初期HTMLも既存のPages動的配信に接続。正常な集計を5分ごとに再検証し、API障害・空集計では最後の正常データとその集計日時を維持。ビルド時の正常HTMLを事前生成し、コールドアクセスでの再描画負荷を抑制。
- モード・マップ一覧、関連リンク、サイトマップが共通の掲載対象を参照。既存の十分なサンプル条件を維持。全対象のAPI取得を1回のWorkerに集中させず、16対象ずつキャッシュに蓄積し、完了した一覧のみ切り替える。更新の途中やAPI障害時は前回の正常一覧を保持する。
- APIが返すタイムゾーンなしのUTC時刻を正規化し、初期HTMLとブラウザー表示を日本時間に統一。実際の集計時刻を使用。

URL、API、集計・Tier計算、低サンプル時のnoindexを維持。説明文・攻略記事・ガイドページの追加なし。`/guide` → `/` の301転送を維持。

本番の変更前HTTP監査（2026-10-16 JST）：サイトマップ193 URL中、200が96、503が97。503のHTMLにはCloudflareの「Worker exceeded resource limits」が表示された。`/maps/ghost-point` はnoindexなのにサイトマップに含まれていた。Google未登録の原因をこの結果だけで断定しない。

変更後の最終ローカルビルド：掲載187 URLすべて200。固有title、h1、自己canonicalを確認。noindex混入・重複title・内部リンク先エラーなし。193→187は既存サンプル条件と現在の実データによる掲載対象の差であり、数を増やすために条件は変更していない。

## 変更内容

### 1. 構造化データ（Dataset 警告 168 件解消・エンティティ強化）
- `frontend/src/lib/site-schema.ts`: `catalogNode()` を追加し、`Organization` に `logo`・`description`・`knowsAbout`、`WebSite` に `about` を付与。
- `frontend/src/lib/llm-data.ts`: 全 `Dataset` に `includedInDataCatalog: catalogNode()`（`@type: "DataCatalog"` 明示）と `license: "https://brawl-lab.sozai-hub.com/about#citation"` を付与。`CollectionPage` / `WebPage` に `dateModified` を連携。
- `frontend/edge/server.tsx`: `/player`・`/companion` に無料ツールを示す `WebApplication` ノードを追加。`/modes/*`・`/maps/*` にも `FAQPage` JSON-LD を出力（`frontend/src/lib/server-condition-pages.tsx`・`frontend/src/app/brawlers/[slug]/page.tsx` も同期）。

### 2. クロール予算・404・未登録キャラ詳細（94 件）の内部リンク改善
- `frontend/edge/public-data.ts`: `/data/*` の JSON / JSON-LD レスポンスに `X-Robots-Tag: noindex, follow` を常時付与し、検索インデックス対象から除外しつつ AI クローラー・`DataDownload` の取得は維持。
- `frontend/src/lib/brawler-page-data.ts`・`frontend/src/app/brawlers/brawler-detail-view.tsx`: 各キャラ詳細に循環隣接＋同レア度の `relatedBrawlers`（最大 6 体）を付与し、全 109 キャラが最低 4 本以上の均等な内部リンクを受け取るグラフ構造を構築。
- `frontend/src/app/not-found.tsx`・`frontend/edge/server.tsx`・`frontend/edge/worker.ts`: 日本語 404 ページと `renderNotFound()` を新設し、単一 `<title>`・単一 `<meta name="robots" content="noindex, follow">`・`X-Robots-Tag: noindex, follow`・主要ページ導線を返すように修正。

### 3. CTR・検索意図一致・LLMO（Answer-First / FAQ / llms.txt）
- `frontend/src/lib/seo.ts`・`frontend/src/lib/page-copy.ts`:
  - `/tier`: 「現環境最強キャラ」を title に追加、ガチバトル 1 位も description に反映。
  - `/player`: 「戦績検索・勝率確認ツール」「登録不要・無料」「戦績の見方」を反映。
  - `/companion`: 「ガチバトル ピックツール｜無料BAN・ピック提案サイト」へ最適化、H1 も一致させ、選択中マップ詳細リンクを追加。
  - `/maps/*`・`/modes/*`: 7 日鮮度ガード付きで `【M/D更新】` を title に付与、description に全体＋ガチバトル上位を要約。`/maps` ハブに「マップ・ステージ別」を追加。
- `frontend/src/lib/page-insights.ts`: `brawlerSummary` にガチバトル成績と「カウンター（苦手な相手）」表記を追加、`conditionSummary` にガチバトル上位を追記。
- `frontend/src/lib/faq.ts`・各 View:
  - `/modes/*`・`/maps/*` にデータ連動 `conditionFaq` と `FaqSection` を新設。
  - `/player` に「戦績の見方・確認できる項目」セクションおよび「戦績の見方」「内部レート（公式 API 非公開のため代替指標を案内）」の FAQ を追加。

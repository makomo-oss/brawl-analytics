# 2026-11-09: SEO・LLMO改善（データ要約・FAQ・/about・llms.txt）

## 背景（Search Console 2026-10-10〜11-06・ウェブ）

- 合計209クリック／5,590表示／CTR 3.7%／平均8.9位。モバイルは4,044表示・CTR 3.0%、PCは1,214表示・CTR 5.6%。
- /player が表示の51%（2,861表示・7.9位）を占める。「ブロスタ 戦績」は400表示・CTR 0.8%・8.4位。「戦績 見方」「勝率 見方」「リザルト 見方」などの情報系の検索は、クリックが0件。
- /tier は18.3位。「最強キャラ ランキング」系の検索は15〜57位。上位の競合サイトは、タイトルに更新日を入れ、本文に上位キャラの一覧を載せている。
- 生成AI機能のレポートは28日で322表示。10/20以降に急増し、「ブロスタ 戦績」のAIによる概要は /player を引用している。
- インデックス登録は24件。検出・未登録が165件で、キャラ・モード・マップの詳細ページの大半がこれに当たる。
- 本番の robots.txt は、Cloudflareの管理機能がAIクローラー（GPTBot、ClaudeBot、Google-Extended など）を拒否する設定を先頭に挿入している。llms.txt は存在しない。

## 変更

### 第1弾（`de4f3ad`）

**共通ライブラリ**

- 新設：`src/lib/dates.ts`、`page-insights.ts`、`faq.ts`、`page-copy.ts`。
- Workerの`<head>`とNextのメタデータが、同じ関数で title・description を作る。
- 使うのは、サンプルが十分な行の実データだけ。データが無効な場合は要約を表示せず、titleとdescriptionは従来の固定文言に戻す。

**ページごとの追加**

| ページ | 追加内容 |
| --- | --- |
| /tier | title に集計日（【11/8更新】。7日を過ぎたら外す）、データ要約、全体Tier上位10の表、FAQ、ItemList と FAQPage の構造化データ |
| /player、/companion | 固定文だけのFAQ。クエリ値やプレイヤーデータは入れない |
| ホーム | ガチバトル環境の要約 |
| キャラ詳細 | title に【Tier】、データ要約、データから作るFAQ（強さ・カウンター・おすすめマップ・味方）、更新日の`<time>` |
| モード・マップ詳細 | データ要約と、データ入りのdescription |
| モード・マップ一覧 | 件数入りの説明文 |

**Workerの`<head>`**

- robots に `max-snippet:-1` と `max-image-preview:large` を指定。
- manifest、theme-color、cdn.brawlify.com への preconnect、OG画像のサイズと代替テキストを追加。

**robots.txt**

- AIクローラーを個別に明示して許可し、`Content-Signal: ai-train=yes` を指定。
- `__companion-snapshots` を Disallow に追加。

**その他**

- runtimeVersion を、`src/lib` と `edge` 以下の全ソースのハッシュに変更。サーバー専用の文言を変えたときも、キャッシュが更新される。

### 第2弾

- サイト共通フッターを追加：主要7ページへのリンク、データの出典、Supercellファンコンテンツポリシーに基づく免責文。ホームにあった既存のフッターは、これに統合した。
- `/about` をruntimeルートとして追加：運営（ブロラボ運営）、データの出典、集計方法、更新頻度、データの扱い、機械可読データ、引用のお願い。AboutPage の構造化データを付けた。
- `/llms.txt` と `/llms-full.txt` をWorkerで生成する。内容は概要、主要ページ、全体Tier上位10、ガチバトル上位、全キャラの統計、モード・マップの一覧、引用のお願い。サイトマップと同じキャッシュとスナップショットを使い、`X-Robots-Tag: noindex` を付ける。
- サイトマップの `/`・`/tier`・一覧ページ・`/about` に lastmod を付けた。

## 未対応・手作業

- **Cloudflareダッシュボード（sozai-hub.comゾーン全体）**：2026-11-09 に次のとおり変更した。
  - 「セキュリティ → 設定 → AI クローラーとエージェントのアクセス ポリシー」で「トレーニング」を「許可しない」から「許可（ブロックしない）」に変えた。検索・エージェント・パーソナルエージェントは元から許可だった。これで AI Crawl Control の32クローラーはすべてブロックなしになった。
